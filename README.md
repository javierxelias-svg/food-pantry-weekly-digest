# Food Pantry Weekly Digest

**A working demo → https://javierxelias-svg.github.io/food-pantry-weekly-digest/**

## The problem

Small food pantries run on a messy spreadsheet and volunteers who aren't technical. All the numbers are in there, donations, stock, families served, but nobody can see the thing that actually matters in the moment: *what are we about to run out of, and what do we ask the community to bring?* By the time someone notices the baby formula is gone, families have already gone without.

## The solution

Type in the week's numbers and it hands you back, instantly:

- **A plain-English brief** the staff can read at a glance, families served, what's fully stocked, what's critically low.
- **A ready-to-post community message**, written for them, asking for exactly what's running low. Copy it, paste it to Facebook or a group chat, done.

Tap − or + on any shelf item (or edit any number) and the whole brief, the needs list and the community post update live. Light and dark mode; works on a phone. No app to install, no training, no login. If you can fill in a number, you can run it.

## Why it's built this way

The whole point is legibility for non-technical people. Messy data goes in, a clear answer comes out. That's the skill, taking something technical and making it make sense to a normal person who just needs to feed their neighbors this week.

One self-contained `index.html`. No build step, no dependencies, no server.

## Honest note

This is a **demo on sample data**, no real pantry's information is shown. It is not a mockup, it actually works, and it's a real day-one starting point for any pantry that wanted it.
